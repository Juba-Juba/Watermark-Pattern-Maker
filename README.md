# Watermark Pattern Maker

تطبيق Flutter عربي RTL لإنشاء أنماط علامات مائية وتصدير PNG شفاف، مع Android وWeb.

## الاستخدام

يوجد تبويبان رئيسيان فقط: **العلامة المائية** و**الفريم**. المعالجة محلية ولا توجد إزالة خلفية.

### العلامة المائية

1. استورد PNG شفافًا؛ يدعم JPG وWebP أيضًا مع الحفاظ على الخلفية الأصلية. الاستيراد لا يعيد توليد النصوص ولا يضغط الصورة. يقص الهوامش الشفافة الخالية فقط، دون حذف أي بكسل مرئي.
2. اللون الأصلي هو الافتراضي. الرصاصي اختياري ويحافظ على تدرجات إضاءة التفاصيل، بدل تحويلها إلى كتلة بلون واحد. لون RGB مخصص اختياري.
3. اختر Grid أو Staggered أو Diagonal. التباعد يُحسب على حدود الشعار بعد الدوران، بما يشمل دوران وحجم الصفوف البديلة، لمنع التداخل. النسب من 100% إلى 500%، وكل محور مستقل مع إمكانية الربط.
4. غيّر الحجم والشفافية والزاوية بالمنزلق أو الرقم. 0% ظهور يخفي الشعار و100% يظهره بالكامل. الضبط التلقائي يتجنب تكبير المصدر الصغير قدر الإمكان؛ التكبير اليدوي فوق دقة المصدر قد يقلل الحدة، ويظهر تنبيه بذلك.
5. افتح أقسام الشعار واللون والمقاس والمحفوظات أسفل الإعدادات. احفظ Presets محليًا وأعد استخدامها. استخدم المعاينة الكاملة مع التكبير حتى 8× لفحص التفاصيل.

### الفريم

1. اختر 9:16 أو 3:4 أو 1:1 أو 16:9، أو أبعادًا مخصصة من 64 إلى 4096 لكل محور. زر 4K يجعل البعد الأكبر 3840.
2. اختر من ستة تصميمات: ناعم، مزدوج، جاليري، أركان، كلاسيك، آرت ديكو. اختر فضيًا أو ذهبيًا أو أبيض أو رصاصيًا أو أسود أو HEX مخصصًا.
3. استورد اللوجو واختر أحد ثمانية مواضع على أضلاع الفريم. تتكون فتحة شفافة حقيقية في خط الفريم حول اللوجو، ويظهر اللوجو فيها بألوانه وأبعاده النسبية الأصلية دون تمديد أو قص أو خلفية مصمتة.
4. عدّل حجم اللوجو، والفراغ حوله، وظهوره، وسمك الفريم وبعده عن الحافة واستدارة الأركان وظهوره. يمكن إخفاء اللوجو أو تصدير الفريم وحده.
5. صدّر PNG شفافًا واستخدمه Overlay في CapCut أو فوق الصورة/الفيديو. خلفية المعاينة لا تدخل في التصدير. Android يفتح منتقي الحفظ الرسمي؛ المتصفح ينزّل الملف.

## البناء

Flutter Stable 3.47.7 / Dart 3.13.5، JDK 17+، Android SDK. استخدم أحدث Flutter Stable متوافق.

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --release
flutter build web --release --base-href / --no-web-resources-cdn
```

APK: `build/app/outputs/flutter-apk/app-release.apk`.

للتوقيع المستقل، انسخ `android/key.properties.example` إلى `android/key.properties` وضع مسار مفتاحك وكلمات مروره. مفتاح النسخة المسلّمة محفوظ محليًا ضمن مجلد `release-signing` المستبعد من Git. لا تفقد المفتاح عند إصدار تحديثات لنفس التطبيق.

## الخصوصية والتفاصيل التقنية

- كل معالجة الصور والرسم وحفظ الإعدادات تتم محليًا؛ لا يوجد API أو خدمة AI أو رفع للصور.
- الاستيراد يحافظ على بكسلات الشعار وألفا الأصلية، ويقص الهوامش الشفافة بالكامل فقط لتحسين حساب الحجم. لا يعدّل النصوص أو يعيد توليد الصورة.
- الحد الأقصى للاستيراد 40MB و20 مليون بكسل، وأقصى بُعد 8192. الصور الأكبر تحتاج تصغيرًا قبل الاستيراد.
- CustomPainter يرسم نفس الصورة عدة مرات دون إنشاء نسخ منها لكل عنصر. التصدير يستخدم PictureRecorder واحدًا، ثم PNG؛ تُحرر الصورة والصورة المسجلة بعد الترميز. ملف 4096×4096 يحتاج ذاكرة RGBA تقارب 64MB بجانب تكلفة Flutter والترميز؛ توجد حراسة لمنع التصدير المتزامن.
- مقاسات الإخراج من 64 إلى 4096 لكل بُعد؛ زر 4K يجعل البُعد الأطول 3840.
- خلفيات المعاينة (شطرنج/أسود/أبيض/صورة) منفصلة تمامًا عن رسم التصدير. لا يتم رسم أي خلفية في PNG.
- اللون الأصلي يحتفظ بألوان الصورة. الرصاصي يستخدم مصفوفة luminance تحافظ على تفاصيل الإضاءة وقناة Alpha؛ RGB المخصص يستخدم Alpha كقناع.
- Photo Picker للاستيراد وStorage Access Framework للحفظ؛ لا حاجة إلى صلاحيات تخزين واسعة أو MANAGE_EXTERNAL_STORAGE. تتم استعادة اختيار الصورة عند إعادة إنشاء Activity عبر retrieveLostData.
- الإعدادات محفوظة على الجهاز/المتصفح، وليست متزامنة بين الأجهزة. عدد العناصر هو حد أقصى للتعبئة؛ العدد المرئي يتأثر بالمقاس والمسافات والإزاحة.
